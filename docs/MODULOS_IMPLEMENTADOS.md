## 📝 Notas Técnicas

1. **Codificação**: Alguns módulos aparecem com caracteres especiais devido à codificação LATIN1 do banco de dados
2. **Módulos específicos**: Alguns módulos são específicos de certos estados/municípios (ex: TCE/MG, Ipasem)
3. **Evolução contínua**: Os módulos estão em constante evolução e melhoria
4. **Customizações**: Muitos municípios possuem customizações específicas sobre os módulos base
